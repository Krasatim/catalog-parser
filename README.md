# Парсер каталога товаров → Excel / CSV / Google Таблицы

Скрипт на Python, который обходит каталог интернет-магазина, собирает данные о товарах и сохраняет их в удобную таблицу.

В качестве демо-источника используется [books.toscrape.com](https://books.toscrape.com) — учебный магазин, созданный специально для практики парсинга. Под реальный сайт скрипт адаптируется заменой CSS-селекторов.

## Что умеет

- Проходит **все страницы каталога** (пагинация по ссылке «следующая»).
- Собирает с карточек в списке: название, цену, валюту, рейтинг, наличие, ссылку, изображение.
- С флагом `--details` заходит в **карточку каждого товара** и добавляет категорию, артикул, остаток на складе и описание.
- Загружает карточки **в несколько потоков**: 1000 товаров с карточками — примерно за минуту.
- **Повторяет запросы** при сетевых ошибках и ответах 429/5xx, делает паузы между страницами.
- Сохраняет в:
  - **Excel** — с оформленной шапкой, фильтрами, закреплённой строкой и кликабельными ссылками;
  - **CSV** — в кодировке и с разделителем, которые корректно открываются в русском Excel;
  - **Google Таблицы** — через сервисный аккаунт Google.

## Установка

Нужен Python 3.10+.

```bash
git clone https://github.com/Krasatim/catalog-parser.git
cd catalog-parser
python -m venv .venv
.venv\Scripts\activate        # Windows
# source .venv/bin/activate   # macOS / Linux
pip install -r requirements.txt
```

## Запуск

```bash
# Весь каталог -> books.xlsx
python parser.py

# Первые 3 страницы -> CSV
python parser.py --pages 3 --out books.csv

# С данными из карточек товаров
python parser.py --details

# С выгрузкой в Google Таблицу
python parser.py --details --sheet "https://docs.google.com/spreadsheets/d/..."
```

| Параметр | По умолчанию | Описание |
|---|---|---|
| `--pages N` | все | сколько страниц каталога обойти |
| `--details` | выкл. | заходить в карточку каждого товара |
| `--workers N` | 8 | число потоков для загрузки карточек |
| `--delay S` | 0.3 | пауза между страницами каталога, сек |
| `--out FILE` | `books.xlsx` | файл результата: `.xlsx` или `.csv` |
| `--sheet URL` | — | ссылка или ID Google Таблицы |
| `--creds FILE` | `credentials.json` | ключ сервисного аккаунта Google |

## Настройка выгрузки в Google Таблицы

1. В [Google Cloud Console](https://console.cloud.google.com/) создайте проект и включите **Google Sheets API** и **Google Drive API**.
2. Создайте **сервисный аккаунт**, затем ключ в формате JSON. Сохраните его рядом со скриптом как `credentials.json` (файл уже добавлен в `.gitignore`).
3. Откройте нужную Google Таблицу и дайте доступ «Редактор» на email сервисного аккаунта (вида `...@...iam.gserviceaccount.com`).
4. Запустите скрипт с параметром `--sheet`.
